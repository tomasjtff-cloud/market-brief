# Research

Each `.md` file in this folder (except files starting with `_` and this README) is published on the app's Research page,
with its track record since the publication date.

To publish a pitch: write it on the Research page ("Write a pitch"), download the `.md` file, then on GitHub open this
folder and use **Add file → Upload files**. The app picks it up after it redeploys (about a minute).

Front matter fields: `title`, `ticker`, `date` (YYYY-MM-DD), `call` (Long / Short / Neutral), `price` (price on the date),
`target` (optional, your price target), `horizon` (optional), `author`.
